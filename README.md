# PELZ LOGS 

## About
Pelz Logs is a fast and secure marketplace for premium accounts in Nigeria. 
We deliver accounts instantly after payment with wallet funding via Paystack.

## How To Use
1. **Sign Up/Login** - Create account on the homepage
2. **Fund Wallet** - Go to Wallet page and fund with Paystack
3. **Shop** - Go to Marketplace, select accounts and click "Buy Selected"
4. **Wait 5 Seconds** - Read the message and click "Continue to Payment"
5. **Get Accounts** - Go to Orders page to copy your purchased accounts and details
